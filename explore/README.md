# explore/ — журнал экспериментов

Здесь лежат рабочие скрипты, на которых проверялись гипотезы из раздела
«Проверенные гипотезы» в корневом `README.md`. Они **не участвуют** в
обучении и предсказании — финальный пайплайн целиком состоит из
`common.py` + `train.py` + `predict.py`.

Скрипты писались в процессе поиска решения и используют свои лёгкие
вспомогательные модули `explore/features.py` (конструктор признаков
экспериментальной версии) и `explore/harness.py` (CV-обвязка), поэтому
могут отличаться от финального `common.py`. Запускать их нужно из корня
репозитория, например:

```bash
python explore/unseen_test2.py      # проверка устойчивости к невидимым категориям
python explore/nested_spline.py     # nested CV для соседних конфигураций сплайнов
python explore/spline_sweep.py      # перебор 48 конфигураций сплайновой логиcтики
```

| скрипт | что проверяет |
|---|---|
| `agg_cmp.py` | ранговая агрегация против вероятностной при выборе порога |
| `derived_check.py` | нужны ли финальной модели 5 производных признаков |
| `ceiling2.py` | потолок F1 при текущем ранжировании (изотоническая калибровка) |
| `comb.py` | перебор всех подмножеств моделей для рангового ансамбля |
| `corr2.py` | скорректированные корреляции Спирмена |
| `diag.py` | тест ёмкости, L1-разреженность, маргинальные AUC |
| `ens.py`, `ens3.py` | ансамблирование: вероятности / ранги / веса |
| `err.py` | разбор ошибок: FN/FP по группам, калибровка по бакетам |
| `f1fast.py` | O(n log n) подбор порога по F1 |
| `final_cmp.py` | сравнение оттюнингованных бустингов и линейных моделей |
| `harness.py` | CV-обвязка (OOF и nested) |
| `linear_div.py` | разнообразие линейных моделей, в т.ч. первая проверка сплайнов |
| `nested_new.py` | nested CV для кандидатов со сплайнами |
| `nested_spline.py` | nested CV для соседних конфигураций сплайнов |
| `screen1.py`–`screen3.py` | первичный отбор признаков и семейств моделей |
| `spline_ens.py` | ансамбль LightGBM + сплайновая логистика, число параметров |
| `spline_sweep.py` | перебор 48 конфигураций сплайновой логистики |
| `sweep_lgb.py`, `sweep2.py` | координатный спуск по гиперпараметрам LightGBM |
| `unseen_test.py`, `unseen_test2.py` | устойчивость к категориям, отсутствующим в train |
| `zoo.py` | зоопарк моделей: LGBM/XGB/CatBoost/MLP/RF/ExtraTrees |

CSV-логи переборов (`sweep_lgb.csv`, `sweep2.csv`, `spline_sweep.csv`)
сохраняются рядом со скриптами.
