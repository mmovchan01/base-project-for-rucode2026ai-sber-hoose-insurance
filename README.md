## 📖 Описание задачи и бизнес-контекст
Крупная компания выводит на рынок новую страховую программу — **«Защищённый смартфон»**, которая покрывает затраты на ремонт или замену экрана смартфона в случае его повреждения.

**Цель:** Построить модель машинного обучения, предсказывающую вероятность покупки клиентом страхового продукта (`accepted` = 1), чтобы максимизировать конверсию маркетинговой кампании.

**Целевая метрика:** **$F_1$-score** на положительном классе (`accepted = 1`).

## ⚡ Быстрый старт (Воспроизведение решения)

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Обучение модели
Запуск скрипта `train.py` обучает ансамбль моделей на 5-фолдовой кросс-валидации, оптимизирует решающий порог и сохраняет обученные веса в папку `models/`:
```bash
python train.py --data train.csv --model_dir models --seed 42 --n_splits 5
```

### 3. Инференс на тестовых данных
Запуск скрипта `predict.py` загружает обученные веса и формирует итоговый файл `submission_seed_42.csv`:
```bash
python predict.py --test_data public_test.csv --model_dir models --output submission_seed_42.csv
```

## 🔍 Разведочный анализ данных (EDA) и ключевые инсайты

1. **Баланс классов:** В обучающей выборке 32.85% положительных исходов (`accepted = 1`) и 67.15% отрицательных (`accepted = 0`).
2. **Стоимость смартфона (`smartphone_price`):** Корреляция $r = 0.7087$ с целевой переменной. Владельцы флагманских смартфонов (Apple, Samsung Galaxy S/Note/Z, Google Pixel) кратно чаще заинтересованы в страховании экрана из-за высокой стоимости ремонта.
   - Конверсия Apple: **81.0%** (средняя цена: 93.4 тыс. руб.)
   - Конверсия Google: **52.2%**
   - Конверсия Samsung: **45.5%**
   - Конверсия Xiaomi: **11.9%**
   - Конверсия Other / Noname: **2.1%**
3. **Платежеспособность (`monthly_income`, `average_monthly_balance`):** Доход ($r = 0.6215$) и остаток на счетах ($r = 0.3857$) прямо пропорциональны готовности приобретать защитные финансовые продукты.
4. **Опыт страхования и маркетинговая активность:**
   - Наличие ранее приобретенных страховок (`previous_insurance`): $r = 0.4155$.
   - Отклик на предыдущую кампанию (`previous_campaign_response`): $r = 0.3429$.
5. **Цифровая активность:** Активные пользователи мобильного банка и клиенты с высокой долей онлайн-транзакций (`online_payments_share`, `mobile_app_usage`) демонстрируют повышенную конверсию.
6. **Доменная структура пропусков:**
   - `loan_amount` пропущен строго при `has_credit == 0` (сумма кредита = 0).
   - `insurance_claims` пропущен строго при `previous_insurance == 0` (нет страховых случаев = 0).
   - `mobile_app_usage` пропущен при отсутствии привязки приложения (сессии = 0).
   - `credit_score` отсутствует у клиентов без кредитной истории (заполняется медианой с индикатором наличия).

## 🏗️ Архитектура модели и ансамблирование

Для достижения максимального $F_1$-score и обобщающей способности был построен ансамбль разнородных градиентных бустингов:

1. **CatBoost (Depth 6)** (вес 0.40): Эффективная работа с комбинациями категориальных признаков (`smartphone_brand`, `region`, `education` и др.) и регуляризация $L_2$.
2. **CatBoost (Depth 5)** (вес 0.30): Модель меньшей глубины для сглаживания локальных переобучений.
3. **LightGBM (31 leaves)** (вес 0.15): Быстрое гистограммное построение деревьев с subsampling по строкам и колонкам.
4. **XGBoost (Depth 5)** (вес 0.15): Exact/approximate split finding с отдельным механизмом регуляризации.

**Формула ансамбля:**
$$P_{\text{ensemble}} = 0.40 \cdot P_{\text{CB, d6}} + 0.30 \cdot P_{\text{CB, d5}} + 0.15 \cdot P_{\text{LGBM}} + 0.15 \cdot P_{\text{XGB}}$$

## 🎯 Стратегия валидации и калибровка порога

- **Схема валидации:** Stratified 5-Fold Cross-Validation с фиксированным `seed=42`. Баланс классов строго сохраняется на всех фолдах.
- **Оптимизация порога:** По умолчанию стандартный порог 0.5 не оптимален для максимизации $F_1$-score при дисбалансе классов. На Out-Of-Fold вероятностях выполняется поиск оптимального порога $\tau^* \in [0.05, 0.95]$ с шагом 0.005:
$$\tau^* = \arg\max_{\tau} F_1(y_{\text{true}}, \mathbb{I}(P_{\text{oof}} \ge \tau))$$
- **Результат калибровки:** Оптимальный порог $\tau^* = 0.4200$.

## 🧠 Осознанность и компактность решения

1. **Компактность параметров:** В решении используются только деревья решений с умеренной глубиной (глубина 5–6), что гарантирует высокую устойчивость к переобучению и быструю скорость инференса (<1.5 секунды на 1000 строк).
2. **Интерпретируемость:** Все сгенерированные признаки имеют ясный экономический и поведенческий смысл.
3. **Воспроизводимость:** Все генераторы случайных чисел зафиксированы (`seed = 42`).
4. **Готовность ко 2-му этапу:** Пайплайн инференса автоматически обрабатывает любые новые категории или пропуски в закрытом тестовом наборе.
